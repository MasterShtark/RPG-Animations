### Bring your character to life.

Wake up, stretch, inspect a treasured find and settle beside a campfire. RPG Animations adds expressive movement to everyday adventures, with animations nearby players can see too.

## Features

- Waking, sleeping, blinking and eye rubbing.
- Walking, sprinting, swimming, climbing, landing, riding and elytra flight.
- Weapon swings, tool use, eating, fishing, pickup and dropping.
- Item inspections, including two-handed equipment and treasure inspections.
- Environmental reactions, idle stretches, typing and social gestures.
- Equipment adjustments, workstation and container interactions.
- Multiplayer animation sharing and opt-in inventory, book and backpack previews.
- Individual animation switches, reduced motion and per-action ownership overrides.

See [CHANGELOG.md](CHANGELOG.md) for the feature list.

## Install

Use Minecraft Java **1.21.1**, NeoForge **21.1.259** and **Java 21**. Put `rpg_animation-neoforge-1.21.1-1.0.0.jar` in the instance's `mods` folder. Install the same build on the server and participating clients. No animation library is required by RPG Animations.

Use the separately labelled 26.3 artifact for Minecraft 26.3. Do not open a 26.3 world in 1.21.1. Back up worlds before changing mods or versions.

## Make it yours

Use the mod configuration screen to choose animations and priorities. Inventory and book sharing is opt-in and lets nearby players see those contents. Chat messages and desktop images are not shared.

| Command | Action |
|---|---|
| `/rpganimation menu` | Gesture menu |
| `/rpganimation preview` | Wake-up preview |
| `/rpganimation skip` | Stop wake-up preview |
